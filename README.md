# POS Analytics Dashboard

Proyecto de análisis de ventas para un sistema POS utilizando un modelo estrella.

## Modelo de Datos
- fact_sales
- dim_product
- dim_customer
- dim_employee
- dim_date

## KPIs
- Total Sales
- Total Quantity Sold
- Average Ticket
- Sales by Product
- Sales by Customer
- Sales by Employee

## Tecnologías
- MySQL
- Power BI
- SQL
- CSV

## Flujo
1. Crear la base de datos.
2. Importar dimensiones.
3. Importar fact_sales.
4. Crear relaciones en Power BI.
5. Construir dashboard de ventas.
